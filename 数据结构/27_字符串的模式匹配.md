- 被查询的文章叫做主串
- 查询的内容叫做模式串
### 字符串的模式匹配：在主串中找到与模式串相同的子串，并返回其所在位置
**模式串不等同于子串**
    - 子串是主串的一部分，一定存在
    - 模式串不一定会在主串当中找的到
__字符串的模式匹配分为两部分__
#### 朴素模式匹配算法 
    实现思想就是暴力解法
        主串长度为 n 模式串长度为 m
        将主串中所有长度为 m 的子串与模式串进行对比，一直到找到一个完全匹配的子串或所有的子串都不匹配为止
    主串长度为n模式串长度为m 只会有 n- m+1 个子串
        int Index(SString S,SString T){
            int i=1,j=1;
            while(i <= S.length && j <= T.length){
                if(S.ch[i] = T.ch[i]){
                    ++i; ++j; 继续比较后继字符
                } else{
                    i = i-j+2
                    j=1
                }
            }
            if(j>T.length)
            return i-T.length;
            else
                return 0;
        }
    最坏时间复杂度是O(mn)
