**要注意是数组下标还是第几个元素**

对称矩阵的 压缩存储：
    对称矩阵当中 aij = aji
    所以我们可以只存储主对角线和上三角区域 或 主对角线和下三角区域（默认 i >= j）
        面对最后的一个元素是 ann 一共有 n(n+1)/2 项
        那么 如果按照行优先原则 aij就是数组中的第 i(i-1)/2 + j 个元素 __如果数组下标是从0开始 那么需要-1__ //先算出来前面的 i-1 行 因为第 i 行还没有满 等差数列求和公式 = (项数)*（首项+尾项）/2 那么也就是 (i-1)((i-1)+1)/2 也就是 i(i-1)/2 + j

        那么 按照列优先原则 aij 也是一样
        如果想访问上三角区的aij 可以利用 aij = aji 来让他变成下三角矩阵

三角矩阵的 存储压缩：
    三角矩阵分为上三角矩阵和下三角矩阵
        上三角矩阵就是 除了上三角区和主对角线之外 其余的都是相同的
        下三角矩阵是 除了下三角区和主对角线之外 其余的是相同的
        压缩方法：以下三角矩阵为例 按照行优先存储 给下三角区和主对角线的元素存储在一维数组当中 然后在最后一个位置存储异常数据 也就是上三角区的那个常量
        占用的空间就是 n(n+1)/2 +1 
        访问正常的元素的时候 元素的位置和对称矩阵的是一样的 i(i-1)/2 + j 那么他的下标就是 i(i-1)/2 + j -1 
        如果想访问那个特殊的元素 那么就访问第n(n+1)/2 +1 个元素 那么他的下标也就是 n(n+1)/2

三对角矩阵的 存储压缩
    三对角矩阵就是在主对角线和其上下两侧的两个对角线有值 其他的数字都是0 所以除了第一行和最后一行有两个元素以外，每一行都有三个元素 所以它转换成一维数组的长度是 3n-2
    也就是当|i-j|>1 的时候 aij = 0
    那么当想在行优先存储的情况下 在一维数组中寻找aij的位置的话：
        前 i-1行 一共有 3(i-1)-1 = 3i-4 个元素 -1是因为第一行只有2个元素
        第 i 行有 j-(i-1)+1 个元素 i-1是因为 三对角矩阵 第 i 行的第一个元素是i-1 后面的加一是要算上 j 自己
        加在一起就是 2i+j-2 个元素 那么他的索引下标就是 2i+j-3(如果下标是从0开始的)
    判断第 k+1 个元素在第几行 第几列
        3(i-1)-1< k+1 < 3i-1
        i >= (k+2)/3
        i = 「(k+2)/3」     k在 (k+2)/3 行（向上取整）
